# Pharmaceutical Supply Chain System

The Pharmaceutical Supply Chain System is a Django-based web application designed to improve transparency, security, and efficiency in pharmaceutical supply chain management.

The system enables secure tracking of medicines from manufacturers to customers while reducing risks such as counterfeiting, theft, diversion, and inefficient manual tracking processes.

---

## Features

- Role-based access control for:
  - Admin
  - Supplier
  - Manufacturer
  - Wholesaler
  - Distributor
  - Customer

- Secure authentication and authorization
- SHA-256 based tamper-proof transaction logging
- Real-time notifications using WebSockets
- Track & Trace dashboard for medicine tracking
- Order and inventory management
- Secure and transparent supply chain workflows
- Responsive user interface
